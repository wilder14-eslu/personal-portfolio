# Wilder Espinoza — Personal Portfolio

Personal portfolio built with React + Vite + Tailwind CSS.

**Live:** [wilder14-eslu.vercel.app](https://wilder14-eslu.vercel.app)

## Tech Stack

- [React](https://reactjs.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Vite](https://vitejs.dev/)
- [Framer Motion](https://www.framer.com/motion/)
- [i18next](https://www.i18next.com/) — EN/ES

## Run locally

```bash
npm install
npm run dev
```

## Environment Variables

Create a `.env` file based on `.env.example`:

```
VITE_GH_TOKEN=your_github_token
```
